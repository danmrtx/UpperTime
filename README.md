# ⏱️ UpperTime - Rastreador de Horas Extras e Pontos CLT

O **UpperTime** é uma aplicação web moderna e progressiva (PWA) desenvolvida para trabalhadores (CLT ou flexíveis) que desejam ter o controle exato do seu banco de horas, horas extras e atrasos antes do fechamento da folha no fim do mês.

---

## ✨ Principais Funcionalidades

- **Batida Instantânea**: Registre o ponto atual com apenas um clique utilizando a hora real do seu dispositivo.
- **Registro Manual**: Adicione ou corrija batidas de horários específicos caso tenha esquecido de bater no momento exato.
- **⚙️ Configuração Individual de Horários**: Cada usuário configura seus próprios horários e jornadas na aba **Config**:
  - Defina quais horários são **Entrada** e quais são **Saída**.
  - O cálculo é inteligente e automático:
    - **Entrada**: Entrar *antes* do horário previsto = **Minutos Positivos (+)** / Entrar *depois* = **Atraso (-)**.
    - **Saída**: Sair *depois* do horário previsto = **Minutos Positivos (+)** / Sair *antes* = **Atraso (-)**.
  - Ative ou desative jornadas para **Sábados** e **Domingos**.
  - As preferências ficam salvas na nuvem vinculadas à sua conta individual.
- **Saldo do Dia e Resumos**: Veja em tempo real seus minutos acumulados no dia, no mês ou filtre por qualquer **Período Personalizado**.
- **Histórico Completo**: Consulte os últimos 60 registros de trabalho e veja o saldo de cada dia.
- **Backup e Exportação CSV**: Exporte todos os seus registros de ponto para planilha Excel/CSV com um clique.
- **Sincronização em Nuvem Segura**: Autenticação com Supabase e isolamento total dos dados de cada usuário via *Row Level Security (RLS)*.
- **PWA (Instalável)**: Pode ser instalado como aplicativo nativo no celular (Android/iOS) ou no computador.

## 🚀 Guia de Deploy Completo na Vercel

O projeto foi totalmente adaptado para rodar na **Vercel** de forma simples, gratuita e rápida, utilizando funções serverless (`/api/config.js`) para injetar de forma transparente as credenciais do seu banco de dados.

---

### Passo 1: Criar o Banco de Dados no Supabase

1. Crie uma conta gratuita em [supabase.com](https://supabase.com) e crie um **Novo Projeto** (New Project).
2. Aguarde cerca de 1 a 2 minutos até o banco ser provisionado.
3. No menu lateral esquerdo, clique no ícone **SQL Editor** (ícone de terminal `>_`).
4. Clique em **+ New query**, cole o código SQL abaixo e clique no botão verde **Run**:

```sql
-- 1. TABELA PRINCIPAL DE PONTOS / HORÁRIOS BATIDOS
CREATE TABLE IF NOT EXISTS tabela_pontos (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  data_registro DATE NOT NULL,
  horario_esperado TEXT NOT NULL,
  horario_real TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

-- Índices para buscas rápidas
CREATE INDEX IF NOT EXISTS idx_tabela_pontos_user_date ON tabela_pontos (user_id, data_registro);

-- Habilita Row Level Security (RLS)
ALTER TABLE tabela_pontos ENABLE ROW LEVEL SECURITY;

-- Políticas de segurança (usuário só vê e altera os seus próprios dados)
CREATE POLICY "Usuários podem visualizar apenas seus próprios pontos"
  ON tabela_pontos FOR SELECT
  USING (auth.uid() = user_id);

CREATE POLICY "Usuários podem inserir seus próprios pontos"
  ON tabela_pontos FOR INSERT
  WITH CHECK (auth.uid() = user_id);

CREATE POLICY "Usuários podem atualizar seus próprios pontos"
  ON tabela_pontos FOR UPDATE
  USING (auth.uid() = user_id);

CREATE POLICY "Usuários podem deletar seus próprios pontos"
  ON tabela_pontos FOR DELETE
  USING (auth.uid() = user_id);

-- 2. TABELA DE CONFIGURAÇÕES INDIVIDUAIS DE HORÁRIOS
CREATE TABLE IF NOT EXISTS configuracoes_usuario (
  user_id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  config JSONB NOT NULL DEFAULT '{}'::jsonb,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

-- Habilita Row Level Security (RLS)
ALTER TABLE configuracoes_usuario ENABLE ROW LEVEL SECURITY;

-- Políticas de segurança para configurações
CREATE POLICY "Usuários podem visualizar suas próprias configurações"
  ON configuracoes_usuario FOR SELECT
  USING (auth.uid() = user_id);

CREATE POLICY "Usuários podem inserir suas próprias configurações"
  ON configuracoes_usuario FOR INSERT
  WITH CHECK (auth.uid() = user_id);

CREATE POLICY "Usuários podem atualizar suas próprias configurações"
  ON configuracoes_usuario FOR UPDATE
  USING (auth.uid() = user_id);

CREATE POLICY "Usuários podem deletar suas próprias configurações"
  ON configuracoes_usuario FOR DELETE
  USING (auth.uid() = user_id);
```

*(Esse script também está disponível diretamente no arquivo `supabase_schema.sql` do repositório).*

### Passo 2: Obter as Chaves do Supabase para o `.env`

No painel do seu projeto no Supabase:
1. Clique no ícone de engrenagem no canto inferior esquerdo (**Project Settings**).
2. No menu lateral de configurações, selecione **API**.
3. Copie os seguintes dados:
   - **Project URL** (Exemplo: `https://abcdefghijk.supabase.co`)
   - **Project API keys** -> Chave `anon` / `public` (Um texto longo começando com `eyJ...`)

---

### Passo 3: O que colocar no `.env` da Vercel

Ao fazer o deploy na Vercel (ou em **Settings > Environment Variables**), configure as seguintes variáveis:

| Nome da Variável | O que colocar | Onde encontrar no Supabase |
|---|---|---|
| `SUPABASE_URL` | `https://seu-projeto.supabase.co` | *Project Settings > API > Project URL* |
| `SUPABASE_ANON_KEY` | `eyJhbGciOi...` (sua chave anon pública) | *Project Settings > API > anon public* |
| `CHAVE_URL` | `3009` *(opcional, pode ser omitido)* | Chave interna da aplicação |

> ⚠️ **Atenção importante com a `SUPABASE_URL`**: Copie o campo **Project URL** (exemplo: `https://xyz.supabase.co`). **NÃO** adicione `/rest/v1` no final! O Supabase gerencia o Auth em `/auth/v1` e as tabelas em `/rest/v1`. Se colocar `/rest/v1` na URL, o login retornará erro 404.

---

### Passo 4: Fazer o Deploy na Vercel

1. Acesse [vercel.com](https://vercel.com) e faça login com sua conta do GitHub.
2. Clique no botão **Add New...** -> **Project**.
3. Localize o repositório **UpperTime** e clique em **Import**.
4. Nas configurações do projeto (**Configure Project**):
   - **Framework Preset**: Deixe em *Other* (ou padrão).
   - **Root Directory**: `./` (padrão).
   - **Build & Development Settings**: Não precisa alterar nada.
   - Abra a seção **Environment Variables** e adicione as variáveis:
     - `SUPABASE_URL` = sua URL do Supabase
     - `SUPABASE_ANON_KEY` = sua chave anônima pública
     - `CHAVE_URL` = `3009`
5. Clique em **Deploy**.
6. Em poucos segundos seu projeto estará online em um domínio como `https://uppertime.vercel.app`! 🎉

---

### Passo 5: Configurar URL de Redirecionamento no Supabase (Auth)

Para que a recuperação de senha e o envio de e-mails de confirmação funcionem com o seu domínio da Vercel:
1. No painel do Supabase, vá em **Authentication** -> **URL Configuration**.
2. No campo **Site URL**, informe a URL da sua aplicação na Vercel:
   ```text
   https://seu-projeto.vercel.app
   ```
3. Em **Redirect URLs**, clique em **Add URL** e adicione:
   ```text
   https://seu-projeto.vercel.app/**
   ```
4. Clique em **Save**.

## 🛠️ Como Usar o UpperTime

### 1. Criando sua Conta
- Abra o site na Vercel.
- Clique em **Cadastre-se**, preencha seu nome, e-mail e crie uma senha.
- Faça login com suas credenciais.

### 2. Configurando seus Horários Individuais (Aba Config)
- Clique na aba **Config**.
- **Dias de Semana (Segunda a Sexta)**:
  - Adicione todos os horários esperados do seu dia (Exemplo CLT 4 batidas: `08:00` Entrada, `12:00` Saída, `14:00` Entrada, `18:00` Saída).
  - Ou configure para 2 batidas diárias (Exemplo: `08:00` Entrada, `17:00` Saída).
  - O sistema permite quantos horários você precisar!
- **Sábado e Domingo**:
  - Ative o interruptor caso você trabalhe no sábado ou domingo e defina os horários.
- Clique no botão **Salvar Horários**. Suas jornadas serão sincronizadas na sua conta!

### 3. Batendo Ponto e Verificando Saldo
- **Hoje**: Veja a lista das batidas previstas para hoje. Basta clicar no ícone da digital para registrar a hora atual.
- **Extras e Atrasos**: O card superior exibe imediatamente quantos minutos você tem de hora extra (verde) ou atraso (vermelho).
- **Período**: Escolha uma data inicial e final para ver o saldo acumulado de dias de trabalho.
- **Exportar CSV**: Na aba **Dados**, clique em **Baixar Backup Completo (CSV)** para gerar um arquivo pronto para abrir no Excel ou Google Planilhas.

---

## 🔒 Segurança

- Todos os dados utilizam **Row Level Security (RLS)** no PostgreSQL do Supabase.
- Cada usuário só consegue visualizar, cadastrar, atualizar ou excluir suas próprias batidas e configurações.
- A chave do Supabase utilizada no frontend é a chave **anon** (pública), projetada nativamente para ser exposta no navegador com a proteção das políticas RLS no servidor.
